# Anthracite

Anthracite is a maintainable soft fork of FreeCAD. The repository tracks a
specific upstream FreeCAD commit and an explicit, ordered series of patches; it
does not vendor FreeCAD or make it a Git submodule.

- Product decisions: [`DECISIONS.md`](DECISIONS.md)
- Upstream and patch workflow: [`WORKFLOW.md`](WORKFLOW.md)

Run `just` to see the available source and patch commands.
